## What changed in 0.3.5

No behaviour change — this release makes the build reproducible, which is what the
community directory's build verification compares:

- The bundled CSL styles and locales are now line-ending normalised, and
  `.gitattributes` keeps every file LF. A fresh clone plus `npm run build`
  reproduces the committed `main.js` byte for byte on Windows, macOS and Linux.
- Previously a CRLF checkout produced a bundle with different escapes for the
  embedded style XML, so "does the committed build match the source" could fail
  for reasons unrelated to the code.

`SHA256SUMS.txt` covers every asset in this release.
