Cite as you write from your EndNote library, then export to Word or LaTeX.

![EndNote Cite in Obsidian](https://raw.githubusercontent.com/XijlI/endnote-cite/main/docs/screenshot.png)

First submission to the Obsidian community directory.

## Install

From the directory once published: **Settings → Community plugins → Browse → EndNote Cite**.
Until then, unzip `endnote-cite-0.3.4.zip` into `<your vault>/.obsidian/plugins/endnote-cite/`
(the `bridge/` folder must sit next to `main.js`) and reload the plugins list.

## What changed in 0.3.4

- Citation text is now built as DOM nodes instead of going through `innerHTML`, so no
  markup from your library can ever be parsed as HTML.
- Removed console logging and gave the manifest a real author name and author URL, per
  the submission requirements.
- README now states the plugin's file access and network behaviour explicitly
  (read-only `.enl` outside the vault, no network, no telemetry).

`SHA256SUMS.txt` covers every asset in this release.
