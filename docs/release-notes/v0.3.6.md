## What changed in 0.3.6

Both blocking findings from the directory review are fixed, plus the cheap warnings.

- **No more direct style assignment.** The group menu still positions itself from
  measured geometry, but only the coordinates are set from code (`setCssProps`); its
  position and look live in `styles.css`.
- **No API newer than `minAppVersion`.** The sidebar now opens with
  `rightSplit.expand()` + `setActiveLeaf()` instead of `revealLeaf()`, and the UI
  language follows the system locale instead of reading Obsidian's internal
  `localStorage` key.
- Review hygiene: `document` → `activeDocument`/`activeWindow` (pop-out windows),
  `createSpan()` / `createFragment()` instead of `document.createElement()`,
  `vault.configDir` instead of a hard-coded `.obsidian`, ES imports instead of
  `require()`, `@codemirror/*` declared as dependencies, no `builtin-modules`,
  no `!important` in the CSS, unused imports and pointless escapes removed.
- `npm run lint` runs the same `eslint-plugin-obsidianmd` rules the scanner uses —
  it currently reports **0 errors**.
- Releases now carry **GitHub artifact attestations**, so the build provenance of
  `main.js` and `styles.css` can be verified.

`SHA256SUMS.txt` covers every asset in this release.
