## What changed in 0.3.7

- **The last remaining style risk is gone.** The group menu now receives its measured
  position as CSS custom properties (`--en-menu-left`, `--en-menu-top`, `--en-menu-width`)
  and the stylesheet owns `left` / `top` / `min-width`, which is the form the directory
  scanner accepts.
- **README now discloses everything the scan asks about**, in a `## Disclosures` section:
  no network traffic (and why the two `fetch` call sites inside the bundled WebAssembly
  loader never open a socket), the read-only `.enl` outside the vault, the export-only
  use of `pandoc` / PowerShell / Word, write-only clipboard access, and the bundled
  `sql-wasm.wasm`.

`SHA256SUMS.txt` covers every asset in this release.
