Cite as you write from your EndNote library, then export to Word or LaTeX.

![EndNote Cite in Obsidian](https://raw.githubusercontent.com/XijlI/endnote-cite/main/docs/screenshot.png)

## Install

1. Unzip `endnote-cite-0.3.3.zip` into `<your vault>/.obsidian/plugins/endnote-cite/` —
   the `bridge/` folder must sit next to `main.js`, the EndNote-field export needs it.
2. **Settings → Community plugins → Reload**, then enable **EndNote Cite**.
3. Point the plugin at your `.enl` file and pick a style.

Desktop only (Windows / macOS / Linux). The live EndNote-field export and the
automatic library refresh additionally need **Windows + Microsoft Word + EndNote**.

## What's new in this release

- **The reference list now keeps itself up to date.** An `endnote-bib` code block
  redraws about half a second after you add or remove a citation, and within 5 s of
  EndNote saving the library — new records, edited authors, years and journal
  metadata included. Before, it rendered once and waited for the manual `↻ Refresh`.
- **Fixed: collapsing a row in the library sidebar.** The details panel used to open
  as a flex sibling and squeeze the title to a sliver, so in a narrow sidebar there
  was nothing left to click. The whole row is now the toggle (`Enter` / `Space` too),
  the details take their own line underneath, a `▸ / ▾` chevron marks the state, and
  the list keeps its scroll position.
- Documented the two ways to get a reference list: static text, or the live block.

## Features

- **Reads your library, never writes it** — the `.enl` SQLite file is opened read-only;
  groups, keywords and the output style all come from the library itself.
- **`[@` completion** in the editor, plus *EndNote: Insert citation* for a search dialog.
  `[@key, pp. 12-13]` adds a locator.
- **Formatted citations in the editor**, rendered with the output style EndNote
  currently has selected (Cite Them Right-Harvard by default).
- **Library sidebar** — search, groups, abstract, and one click to cite the note you
  were last editing.
- **Word, two ways**: plain pandoc text, or real `ADDIN EN.CITE` + `EN.REFLIST` fields
  that Word's *Update Citations and Bibliography* still understands.
- **LaTeX / BibTeX / CSL JSON** export.
